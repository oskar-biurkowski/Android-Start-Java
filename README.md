# Projekt: HelloApp (Android M01 – Java)

Aplikacja mobilna stworzona w Android Studio przy użyciu języka Java (minimum SDK 26).

## Struktura projektu
- `MainActivity.java`: Główna aktywność (Activity) sterująca logiką ekranu.
- `activity_main.xml`: Układ interfejsu użytkownika (ConstraintLayout z TextView i Button).
- `strings.xml`: Zasoby tekstowe z obsługą lokalizacji.

## Uruchomienie
1. Otwórz folder projektu w Android Studio.
2. Poczekaj na zakończenie synchronizacji Gradle.
3. Uruchom aplikację na emulatorze lub fizycznym urządzeniu (zielony trójkąt ▶).
